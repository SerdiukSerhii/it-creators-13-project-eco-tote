👜 Eco-Tote — Style That Cares for the Planet

Eco-Tote is a responsive landing page focused on environmental awareness and promoting a more sustainable lifestyle through the use of reusable eco-friendly bags.

The project demonstrates a modern responsive layout, interactive elements, and a modular development approach based on a Figma design.

🎯 About the Project

Eco-Tote encourages users to make more conscious everyday choices by exploring sustainable alternatives to traditional bags.

The website showcases:

🌱 Benefits of using reusable eco-friendly bags
👜 Available product assortment
💬 Customer feedback
🖼️ Product gallery
📩 Support form
📱 Responsive design for different screen sizes

📄 Live Page: View the project

📐 Responsive Design

The project was tested and optimized for different screen sizes:

📱 Mobile: Mobile-first approach starting from 375px
📟 Tablet: Responsive layout from 768px
💻 Desktop: Layout optimized for 1440px

The interface adapts to different screen sizes while maintaining the original Figma design and usability.

⚙️ Getting Started
1. Clone the repository
git clone https://github.com/yevhenii-priadko/it-creators-13-project-eco-tote.git
2. Navigate to the project directory
cd it-creators-13-project-eco-tote
3. Install dependencies
npm install
4. Start the development server
npm run dev

The project will be available at the local development URL provided by Vite.
